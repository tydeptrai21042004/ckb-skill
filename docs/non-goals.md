# MVP Non-goals

1. Mainnet launch — testnet first so failures carry no real-value risk.
2. Marketplace — prove one useful capability before discovery infrastructure.
3. Token speculation — the Cell represents service authorization, not a speculative token.
4. Fully autonomous agent wallet — delegation comes later and never requires the owner's private key.
5. Reputation — unrelated to proving ownership-following access.
6. RGB++ — unnecessary for the first CKB-native state machine.
7. Production legal licensing — the MVP is a technical authorization experiment.
8. Cross-chain support — adds complexity before the core CKB flow is verified.
9. Fiber/x402 — deferred until the transfer/access invariant is working.
10. Spore/JoyID-specific UX — optional after the custom script is proven.
