# Vercel build fixes in this package

This package incorporates the fixes needed for the Vercel errors observed during deployment.

## Fixed

- Removed invalid direct `services.*.maxDuration` properties from `vercel.json`.
- Kept the Vercel Services layout for `web`, `api`, and `facilitator`.
- Restored hardened security headers in `vercel.json`.
- Converted the repository into an npm workspace (`apps/*`, `packages/*`).
- Made `apps/web` depend explicitly on `@skillpass/ckb-client` and `@skillpass/capability-codec`.
- Added package exports/version metadata for `@skillpass/ckb-client`.
- Replaced brittle `../../../packages/...` frontend imports with workspace package imports.
- Replaced relative capability-codec imports inside `ckb-client` with workspace imports.
- Restricted the web TypeScript project to `src`; imported workspace files are followed transitively instead of compiling every example in `ckb-client`.
- Kept the `ckb-std 1.1.0` Type-ID compatibility fix in the Rust contract.
- Updated `collect-vercel-env.sh` to support OffCKB 0.4.7 plain-text `accounts`/`balance` output as well as newer JSON-capable releases.
- Restored `.env.*.example`, `.gitignore`, and `.dockerignore` release files.

## Before pushing

From the repository root:

```bash
npm install
npm run build:web
npm test
npm run security:preflight
```

Commit the generated root `package-lock.json` after `npm install`. This makes transitive dependencies reproducible on Vercel.

Then push to the branch connected to Vercel.

## Vercel GUI

- Project framework: Services
- Root Directory: repository root
- Paste values generated by `bash collect-vercel-env.sh` into Environment Variables.
- Connect Neon through Vercel Storage/Marketplace so `DATABASE_URL` is injected.
- Do not manually set `FACILITATOR_URL`; the Vercel service binding provides it.
