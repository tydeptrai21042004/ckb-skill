What success looks like

  1. Alice can use the service before transfer.
  2. Alice transfers the capability to Bob.
  3. Alice is rejected after transfer.
  4. Bob can use the same capability.
  5. A paid request requires both a valid Fiber payment proof/state and current capability ownership.
