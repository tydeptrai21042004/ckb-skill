# CKB Testnet Evidence

This directory is reserved for **real chain evidence**, not simulated demo output.

Before marking the funding milestone complete, add a machine-readable `manifest.json` containing the real contract deployment, issuance, Alice->Bob transfer, pre/post outpoints, source commit, block/confirmation data, and provider evidence hashes.

Do not replace transaction references with screenshots. Screenshots may be supplementary only.

See `docs/FUNDING_ACCEPTANCE_MATRIX.md` for required fields.
